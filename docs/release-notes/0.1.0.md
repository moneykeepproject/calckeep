# CalcKeep 0.1.0

> **0.1.0 was published for Windows only.** The Mac download described below came in
> [0.1.1](0.1.1.md).

CalcKeep is a set of financial calculators: mortgages, car loans and leases, paying
off debt, retirement, savings, investments, taxes, insurance, small business, real
estate and college. Type or slide in your numbers and see the answer straight away.
Everything stays on your computer.

This is the first public release. Please read [Known limits](../known-limits.md).

## What's in 0.1.0

- **57 calculators in 13 groups:** Mortgage, Auto Loan, Auto Lease, Pay Off, Loan,
  Retirement, Savings & CD, Investments, Tax, Insurance, Business, Real Estate and
  Education. The [README](../../README.md) lists every one.
- **2026 figures:** federal tax brackets and standard deduction, long-term capital
  gains brackets, 401(k), IRA and HSA limits, the Social Security wage base and the
  IRS table for required minimum distributions.
- **Easy entry:** a keypad for amounts with quick-add buttons, sliders for rates and
  terms, and buttons for small choices. Fields appear only when they apply. On a
  computer you can also type.
- **History** keeps your last 30 calculations. Tap one to reopen it with the same
  numbers. Each calculator also remembers the numbers you used last.
- Light and dark themes, following your system or chosen with the sun/moon button.
- A layout that fits both a large window and a narrow one.

## Install

### Windows (64-bit)

- **With MoneyKeep Launcher:** install the launcher, then choose **Install** on
  CalcKeep. It downloads the setup, checks it and runs it. Windows asks for
  administrator permission.
- **From the release:** download `calckeep-0.1.0-windows-x64-setup.exe` and run it.
  It installs CalcKeep for all users in `C:\Program Files\CalcKeep` (Windows asks for
  administrator permission), with a Start menu shortcut and, if you choose, a desktop
  shortcut.

The setup is not signed yet, so Windows SmartScreen may warn: choose **More info**,
then **Run anyway**.

A newer setup updates CalcKeep in place. When you uninstall it (Settings > Apps >
Installed apps), it asks before deleting your history.

### Mac (macOS 11 or later, Apple silicon and Intel)

- **From the release:** download `calckeep-0.1.0-macos-universal.dmg`, open it and
  drag CalcKeep to Applications.
- **With MoneyKeep Launcher:** on a Mac the launcher can't install CalcKeep yet (see
  [Known limits](../known-limits.md)). Install it from the release as above; the
  launcher then finds it, opens it and tells you when a new version is out.

This Mac build is not yet signed with an Apple Developer ID, so macOS warns the first
time you open it. Right-click (or Control-click) CalcKeep in Applications, then choose
**Open**, and confirm. If macOS doesn't offer **Open**, go to System Settings > Privacy
& Security, scroll down and choose **Open Anyway** next to CalcKeep. You only need to
do this once.

## Checking your download

Each release has a file called `SHA256SUMS.txt`. It lists a fingerprint (a SHA-256
checksum) for every file in the release. MoneyKeep Launcher checks it for you. To check
a file yourself:

- **Windows:** open PowerShell in the folder with the file and run
  `Get-FileHash .\calckeep-0.1.0-windows-x64-setup.exe -Algorithm SHA256`
- **Mac:** open Terminal in the folder with the file and run
  `shasum -a 256 calckeep-0.1.0-macos-universal.dmg`

Compare the long string it prints with the one next to the file's name in
`SHA256SUMS.txt` (capital and small letters count as the same). If they differ, don't
open the file: download it again.
